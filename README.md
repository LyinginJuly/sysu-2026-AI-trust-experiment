实验文件使用方法说明：

实验过程中不能点击刷新或F5，否则会回到首页，丢失所有数据。

实验一二：
- 由于文件是纯前端文件，点开即可在浏览器运行。
- 须确保头像文件与html文件处于同一个文件夹，以正确在网页中引用。

数据保存说明：
- 结束页实验数据会自动保存。
- 数据保存后会以json格式下载到电脑/downloads文件夹，可以用vscode打开查看，也可保存后集中处理。

实验三：

Method 1 (Terminal; 最新版 untested):

- 安装 nodejs, 确保可以使用 npm 和 node
- 检查方法：在终端中输入 `npm -v` 和 `node -v` 若均能显示版本号则成功
- 实验三文件夹下载到本地，终端进入实验三文件夹
- 使用 `npm install` 命令配置环境
- 配置完成后，输入 `node server.js` 运行程序
- Ctrl + 左键终端中给出的网址，跳转到实验程序

Method 2 (下载 + Terminal; 目前未将最新版打包为rar):

- 当前仍属于编码环境，需提前在电脑上安装nodejs以运行。
启动运行：
  - 解压缩；
  - 在vscode中打开文件；
  - 启动终端（terminal）；如果找不到，在左上角View->Terminal。用电脑自带的终端也可以。
  - 确认切换到实验三文件夹；
  - 输入：node server.js（运行后端）；
  - 实验三的运行网址会出现在[localhost:3000](http://localhost:3000/%E5%AE%9E%E9%AA%8C%E4%B8%89%E4%BA%8C%E9%98%B6%E6%AE%B5.html)。

AI调用说明：
  - AI的提示词、验证逻辑均在后端。
  - 由于安全考虑和后台限制，AI必须通过后端调用。
  - 因此，我们将不得不考虑以服务器或打包成exe的方式部署。
