# sysu-2026-AI-trust-experiment
当前最新版本为可用版1.2内的两个通用html文件。

  实验组对应：
  - A组：伙伴-伙伴（第一印象=伙伴，行为模式=伙伴）
  - B组：伙伴-工具（第一印象=伙伴，行为模式=工具）
  - C组：工具-伙伴（第一印象=工具，行为模式=伙伴）
  - D组：工具-工具（第一印象=工具，行为模式=工具）

实验文件使用方法说明：

实验过程中不能点击刷新或F5，否则会回到首页！！

实验一二：
由于文件是纯前端文件，点开即可在浏览器运行。
须确保头像文件与html文件处于同一个文件夹，以正确在网页中引用。

数据保存说明：
结束后点击保存按钮保存实验数据。注意保存后才能退出！
数据保存后会以json格式下载到电脑/downloads文件夹，可以用vscode打开查看，也可保存后集中处理。

实验三：
需提前在电脑上安装nodejs以运行。
启动运行：
  解压缩；
  在vscode中打开文件；
  启动终端（terminal）；如果找不到，在左上角View->Terminal
  确认切换到实验三文件夹；
  输入：node server.js（运行后端）；
  实验三的运行网址会出现在[localhost:3000](http://localhost:3000/%E5%AE%9E%E9%AA%8C%E4%B8%89%E4%BA%8C%E9%98%B6%E6%AE%B5.html)。

AI调用说明：
  AI的提示词、验证逻辑均在后端。
  由于安全考虑和后台限制，AI必须通过后端调用。
  因此，我们将不得不考虑以服务器或打包成exe的方式部署。
